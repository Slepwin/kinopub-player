# KinoPub Player

Десктопный плеер для [kino.pub](https://kino.pub) на Electron, оформленный в духе
классического **Media Player Classic**: строка меню, компактный тулбар с кнопками
транспорта, синий сикбар и статус-бар. Функциональность повторяет Kodi-аддон
[kodi.kino.pub](https://github.com/quarckster/kodi.kino.pub) и использует тот же API.

## Возможности

- **Авторизация устройства** через OAuth device flow (код + kino.pub/device), авто-обновление токена, сброс авторизации.
- **Разделы**: Фильмы, Сериалы, ТВ-шоу, 3D, Концерты, Документальные фильмы и сериалы — с вкладками *Свежие / Горячие / Популярные / Алфавит / Жанры / Сортировка* и постраничной навигацией.
- **Поиск** с историей (размер настраивается, историю можно очистить).
- **Карточка**: постер, описание, рейтинги IMDB/Кинопоиск, жанры, актёры, режиссёр, статус сериала; сезоны и эпизоды с отметками просмотра и позициями паузы.
- **Воспроизведение**: HLS (hls.js) с выбором качества (480p–2160p), типа потока (hls/hls2/hls4) и CDN (Россия/Нидерланды); выбор аудиодорожки; внешние субтитры (srt) и встроенные HLS-субтитры; автопереход к следующему эпизоду.
- **Прогресс как в аддоне**: продолжение с места остановки, отметка «просмотрено» после 90%, сохранение позиции (`watching/marktime`), сброс позиции при остановке в первые 3 минуты; периодическая синхронизация каждые 30 с.
- **«Я смотрю»** (подписки на сериалы со счётчиком новых серий) и **Недосмотренные фильмы** с полосой прогресса.
- **Закладки**: папки (создание/удаление), добавление и удаление элементов через мультивыбор.
- **Подборки** (свежие/горячие/популярные) и **ТВ-каналы** (прямые HLS-потоки).
- **Контекстное меню** на карточках: смотреть, «Буду смотреть», просмотрено/не просмотрено, закладки, комментарии kino.pub, похожие, трейлер.
- **Настройки**: качество, тип потока, CDN, «спрашивать качество», сортировка, исключение аниме, пометка контента с рекламой, видимость пунктов меню, размер истории поиска.
- **Профиль**: имя, дата регистрации, остаток дней подписки.

## Управление (как в MPC)

| Клавиша | Действие |
|---|---|
| `Space` | Пауза / воспроизведение |
| `F` | Во весь экран |
| `M` | Без звука |
| `←` / `→` | −10 / +10 сек (`Shift` — 60 сек) |
| `↑` / `↓` | Громкость |
| `Backspace` | Назад (в плеере — к библиотеке) |
| `Esc` | Выход из полноэкранного режима |
| Двойной клик по видео | Во весь экран |
| ПКМ по карточке | Контекстное меню |

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm start
```

При первом запуске появится диалог активации: откройте указанный адрес
(https://kino.watch/device) и введите код с экрана.

## Сборка для Windows 11

```bash
npm run dist:win
```

Артефакты появляются в `dist/`:

- `KinoPub Player-1.0.0-win.zip` — портативная сборка: распаковать и запустить
  `KinoPub Player.exe`. Собирается и на Linux, и на Windows.
- `KinoPub Player Setup 1.0.0.exe` — NSIS-инсталлятор (с ярлыками и деинсталлятором).
  На Linux для него требуется **wine** (`sudo apt install wine64`); на самой
  Windows он собирается без дополнительных зависимостей.

На Windows перед сборкой: установить Node.js 18+, затем `npm install && npm run dist:win`.
Windows может показать предупреждение SmartScreen — сборка не подписана
сертификатом; выберите «Подробнее → Выполнить в любом случае».

Иконка приложения лежит в `build/icon.png`; electron-builder сам конвертирует
её в нужные форматы, включая иконку exe. Из-за этого локальная сборка Windows-целей
на Linux требует wine (правка ресурсов exe); основной путь выпуска — CI на
Windows-раннере (см. «Автоматические релизы»), там всё собирается нативно.

## Сборка для macOS

```bash
npm run dist:mac
```

Цели: **dmg** и **zip**, обе для Apple Silicon (arm64) и Intel (x64).

- **dmg** собирается только на macOS (нужен системный `hdiutil`).
- **zip** можно собрать и на Linux/Windows:
  `npx electron-builder --mac zip --arm64` (и/или `--x64`).
  Распаковать, перетащить `KinoPub Player.app` в «Программы».

Сборка не подписана и не нотаризована (`identity: null`), поэтому Gatekeeper
при первом запуске сообщит, что приложение «повреждено» или «от неустановленного
разработчика». Снять карантин:

```bash
xattr -cr "/Applications/KinoPub Player.app"
```

либо: Системные настройки → Конфиденциальность и безопасность → «Всё равно
открыть». Для подписи/нотаризации нужны Apple Developer ID и сборка на macOS.

## Сборка для Linux

```bash
npm run dist:linux   # все цели: AppImage + deb + pacman
npm run dist:deb     # только Ubuntu/Debian
npm run dist:arch    # только Arch Linux
```

Артефакты появляются в `dist/`:

- `KinoPub Player-1.0.0.AppImage` — универсальный: `chmod +x` и запустить.
- `kinopub-player_1.0.0_amd64.deb` — Ubuntu/Debian:
  `sudo apt install ./kinopub-player_1.0.0_amd64.deb`.
- `kinopub-player-1.0.0.pacman` — Arch Linux:
  `sudo pacman -U kinopub-player-1.0.0.pacman`.

Для pacman-цели нужен `bsdtar` (`sudo apt install libarchive-tools` на
Ubuntu; на Arch входит в базовый `libarchive`).

## Автоматические релизы (GitHub Actions)

Workflow `.github/workflows/build.yml` собирает приложение под Windows, macOS
и Linux. Запуск:

- **пуш тега `v*`** — сборка на всех трёх ОС и публикация GitHub Release
  со всеми артефактами:

  ```bash
  git tag v1.0.0
  git push origin v1.0.0
  ```

- **вручную** — вкладка Actions → Build → Run workflow; артефакты будут
  доступны в результатах запуска без создания релиза.

На Windows-раннере NSIS-инсталлятор собирается нативно (wine не нужен).

## Структура

```
src/main/       главный процесс: окно, IPC, OAuth, API-клиент, настройки
  main.js       создание окна, регистрация IPC
  api.js        клиент api.srvkp.com: device flow, refresh, 401/429 retry, фильтр аниме
  store.js      настройки в userData/settings.json
  preload.js    contextBridge → window.kp
src/renderer/   интерфейс (MPC-стиль)
  js/api.js     обёртки эндпоинтов, выбор качества/потока/CDN
  js/player.js  hls.js, дорожки, субтитры, очередь эпизодов, marktime-логика
  js/views.js   экраны библиотеки, контекстные меню, закладки, комментарии
  js/app.js     меню, сайдбар, клавиатура, авторизация, настройки
  js/util.js    диалоги, контекстное меню, тосты
  vendor/       hls.min.js
```

Настройки и токены хранятся в каталоге данных приложения
(`~/.config/kinopub-player` на Linux, `%APPDATA%/kinopub-player` на Windows).
